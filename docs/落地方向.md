# 落地方向（给这个项目的"第一刀"选择）

> 配套：`docs/优化环节清单.md`（怎么改造）、`docs/实验报告_*.md`（三域数据）、`docs/简历项目描述.md`（怎么讲）。
> 本文件回答：**这项目能卖给谁 / 用在哪，第一刀砍哪里。**

## 0. 一句话定位

把「LLM 训练数据 / RAG 知识库 / 合成数据」里**一条被内容级篡改过的投毒文本**在入库前拦下来——词面过滤抓不住（edit 召回 0.014~0.040），人工看不过来（百万条），语义判官太贵（0.78~1.36s/条）——所以做成**学生模型毫秒级粗筛 + 判官 TopK 精判 + 级联召回-成本曲线**的三层流水线。

## 1. 四种真实落地形态（按成熟度排）

### ① 入库数据安全网关（离业务最近）
- 场景：任何要做 LLM 微调 / 提示工程 / RAG 的企业，入库前数据清洗。
- 现成资产：`PoisonScorer` + FastAPI `/score /health /stats`（10–25ms/条，批量上限 512）；批量扫描 `examples/scan_iflytek.py` 扫全量；TopK 级联 `examples/repro_scene4.py`。
- 卖点：私有化、离线、毫秒级。0.5B 判官 + 蒸馏学生 = 两个本地文件，**数据不出域**（金融/医疗/政务硬需求）。

### ② RAG 知识库语料审核（①的特化，推荐第一刀）
- 场景：向量库写入前把文档/问答对过一遍。知识库被塞一条恶意/虚假文档 → 检索命中 → 污染生成，是 RAG 最经典投毒面。
- 现成逻辑：`repro_scene4` 的「学生粗排 → 判官精判 → 按预算收口」是现成骨架。
- **afqmc 实证刚确认：短文本域（RAG 碎片 / QA / 评论）整条链最强**——词面法对 edit 召回 0.674（长句域只有 0.014），判官 AUROC 三域最高 0.783，学生 0.104ms/条。这是离钱最近、效果又最漂亮的方向。

### ③ 私有化离线产品（小改动）
- 现状：`poisonguard` 已 `pip install`-able，但绑在完整流水线里。切一个 `poison-scan <file> --report` 单文件用法即可当独立工具卖。
- 卖点：**开箱换域**——换一份干净语料文件，全流程自动（三域验证过）。

### ④ 合成训练数据质量门（跟热点绑定）
- 合成数据微调 LLM 现在是主流，合成数据天然带分布外/毒化样本。本工具可作合成管线质量门：学生毫秒级全量粗筛 → 判官复核 TopK。

### ⑤ 红队演练 / 评测基准平台（投入重，不推第一刀）
- 现成攻击家族生成器（五族 + edit + 硬负样本）+ 级联召回-成本曲线 + 注入红队 = 一个"给企业量化内容安全系统能打程度"的评测框架。工具型产品，获客/交付重。

### ⑥ 在线审核（红海，放弃）
- 与成熟内容审核厂商正面竞争，判官仅 0.5B + 五类攻击，通用审核无胜算。

## 2. 推荐第一刀：②（RAG 入库守卫）

理由：
1. **离钱近**——RAG/合成数据是当前 LLM 工程的最大数据入口，投毒痛点是刚需；
2. **工程缺口最小**——服务、批量扫、级联、蒸馏全齐，只缺"适配用户文件格式 + 人类可读报告"；
3. **诚实数据就是销售话术**——"内容级篡改，词面方法召回 4%，语义判官抓 37.5~57.5%，毫秒级"本身就是产品存在的证明。

## 3. 落地要补的三件事（进度：1✅ 2✅ 3✅）

1. **`scan` 命令** ✅ 已实现（`poisonguard scan`，2026-11-11）：任意 txt/csv/jsonl → 分数 + 视图分解 + BLOCK/WATCH/PASS 分档 + TopK 判官复核 + 人审报告（Markdown/HTML/CSV/JSON 四件套）。实测 afqmc 域 20 条混合输入 **5.56 ms/条** 全量打分；判官复核自动读该域 dev 校准阈值（afqmc 0.8845），双阈值联合结论。
   ```bash
   python -m poisonguard.cli scan --clean-source tnews --real-file real_afqmc.txt --edit --hardneg 400 \
       --input 你的文本文件.txt --judge-topk 20
   # 产物 outputs/scan/<输入名>.report.md / .report.html / .scores.csv / .json
   ```
2. **HTML/Markdown 审阅报告** ✅ 已随 scan 落地（人审兜底，直面误报问题）；
3. **`poisonguard-deploy` 单文件发布物** ✅ 已实现（2026-11-12）：`deploy` 只打包**拟合态**（kNN 参考句向量 / 字符 n-gram 分类器 / 校准分布 / 蒸馏学生 / 域阈值），**不含原始文本**；`run` 在部署机加载 `.pkg` 离线批扫，只需公共编码器权重。afqmc 包 42 MB（`--quantize i8` 压到 **10.9 MB**，520 条样本分档 0 处改变）、`.pkg` 带 sha256 校验，与作者侧装配逐条分数差 **0**、分档 0 处不一致 → "数据不出域"成立且可验证。
   ```bash
   # 作者侧
   python -m poisonguard.cli deploy --clean-source tnews --real-file real_afqmc.txt --edit --hardneg 400
   # 部署侧
   python -m poisonguard.cli run --bundle outputs/deploy/poisonguard-afqmc.pkg \
       --input 你的文本文件.txt --judge-topk 20
   ```

## 4. 三域验证对照（2026-11-07 实跑）

| 域 | 领域 | 平均句长 | sup_tfidf AUROC / edit 召回 | 判官 AUROC / edit@0.5 | 学生 AUROC / 延迟 |
| :-- | :-- | --: | --: | --: | --: |
| tnews（基线） | 新闻标题 | 28 字 | 0.938 / 0.040 | 0.689 / 0.525 | 0.692 / 0.045 ms |
| iflytek | App 描述 | **289 字** | 0.898 / 0.014 | 0.721 / 0.375 | 0.767 / **0.152 ms** |
| **afqmc** | 金融问答 | 13 字 | **0.990 / 0.674** | **0.783 / 0.575** | 0.752 / **0.104 ms** |

**核心机制结论**：词面法对"内容级篡改"的抓取 = 句长/信息密度的函数。短文本域（13 字）单点编辑会改掉高权重字符 n-gram，词面法直接够强；长文本域（289 字）单点替换淹没在噪声里，必须靠语义层。→ **落地方向直接分化：RAG 碎片 / QA / 评论 → 词面法可先挡一版；长文档 → 语义判官预算必须给足。**
